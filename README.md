# JavaScript Array Methods

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?style=flat-square&logo=javascript&logoColor=black)

## Overview

This repository contains JavaScript exercises focused on declarative array methods and working with collections of objects.

## Tech Stack

- JavaScript
- HTML
- Git & GitHub

## Tasks

### User Name Extraction
Uses `map()` to create an array of user names from a collection of user objects.

### Friend Filtering
Uses `filter()` and `includes()` to find users connected to a selected friend.

### Sorting by Friend Count
Uses `toSorted()` to order users by the number of friends.

### Balance Aggregation
Combines `filter()` and `reduce()` to calculate total balances by gender.

## Learning Outcomes

- `map()`, `filter()`, `reduce()`;
- immutable sorting with `toSorted()`;
- chaining array methods;
- processing arrays of objects;
- writing concise arrow functions.
